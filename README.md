🧠 Mini NPU Simulator Project
파이썬을 활용하여 인공지능 가속기(NPU)의 핵심 연산 원리를 이해하고 구현하는 학습용 프로젝트입니다.

📌 프로젝트 개요
이 프로젝트는 NPU의 기본 동작 원리인 MAC(Multiply-Accumulate) 연산, Bias 추가, ReLU 활성화 함수를 직접 구현하면서,
작은 인공지능 연산 엔진이 어떤 방식으로 동작하는지 학습하는 것을 목표로 합니다.

또한 입력 데이터 파일을 프로젝트에 포함하고 GitHub로 관리하면서,
코드 작성 + 파일 관리 + 버전 관리까지 함께 연습하고 있습니다.

두 행렬의 MAC 연산 수행
