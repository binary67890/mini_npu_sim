🧠 Mini NPU Simulator Project
파이썬을 활용하여 인공지능 가속기(NPU)의 핵심 연산 원리를 이해하고 구현하는 학습용 프로젝트입니다.

📌 프로젝트 개요
실제 NPU 하드웨어가 데이터를 처리하는 방식(MAC 연산, 활성화 함수 등)을 소프트웨어적으로 시뮬레이션하여 딥러닝의 기초 구조를 학습합니다.

🛠 현재까지 구현된 기능 (Step 1 ~ 2)
1. 기초 연산 엔진 (Basic Operations)
MAC (Multiply-Accumulate) 연산: 입력값과 가중치를 곱하고 더하는 NPU의 가장 핵심적인 연산을 구현했습니다.
다차원 배열 처리: 1D 리스트 및 2D 행렬 형태의 데이터를 처리하는 기초 로직을 작성했습니다.
2. NPU 클래스 설계 (NPU Engine)
객체 지향 설계: NPU 클래스를 통해 가중치(Weights)와 바이어스(Bias)를 관리합니다.
활성화 함수 (ReLU): 연산 결과가 0보다 작으면 0을, 크면 그 값을 그대로 출력하는 비선형 함수를 추가했습니다.
연산 로그 기능: 내부 계산 과정(입력, 가중치 곱, 바이어스 합산 등)을 실시간으로 확인할 수 있는 로그 기능을 탑재했습니다.
📂 파일 구조
npu_engine.py: NPU의 핵심 로직과 클래스가 담긴 메인 파일
README.md: 프로젝트 설명 및 진행 상황 기록
🚀 실행 결과 예시
현재 NPU 엔진은 다음과 같은 흐름으로 계산을 수행합니다:

입력 데이터와 가중치의 행렬 곱 수행
결과값에 Bias(편향) 가산
ReLU 함수를 통과하여 최종 출력값 산출 (예: 5.0)
📈 진행 상황 (Roadmap)
Step 1: 기초 MAC 연산 및 배열 처리 구현
Step 2: NPU 클래스 설계 및 활성화 함수 추가
Step 3: 다층 구조(Multi-layer) 신경망 연결 (진행 예정)
Step 4: 실제 데이터를 활용한 논리 연산 테스트
